# Identidad de Marca: MercaIntelligence

Este documento define la visión estratégica, los valores y la identidad visual de **MercaIntelligence**, estableciendo una guía de estilo coherente para el desarrollo del proyecto y su presentación pública (TFE).

## 1. Visión y Propósito

**MercaIntelligence** nace como una herramienta de entender el camportamiento de los productos de Mercadona, su evolución, sus variaciones y tendencias. Su objetivo es aplicar técnicas de Inteligencia Artificial (NLP, XGBoost) y Big Data para monitorizar de forma continua el catálogo completo de Mercadona (~4.300 productos).

*   **Misión:** Dar a conocer al usuario el comportamiento de los productos de Mercadona y aportar transparencia frente a prácticas comerciales como la reduflación (*shrinkflation*).
*   **Visión:** Convertirse en una herramienta de referencia para el análisis del comportamiento de productos de Mercadona y/o otros supermercados.

## 2. Pilares Estratégicos (Valores)

1.  **Transparencia Radical:** Exponer la realidad de las fluctuaciones de precios y cambios de formato (peso/volumen) sin filtros.
2.  **Rigor Analítico:** Los datos presentados están respaldados por modelos de Machine Learning y detección robusta de anomalías.
3.  **Empoderamiento del Consumidor:** Devolver el control al usuario común ofreciendo métricas comprensibles (ej. IPC propio).
4.  **Innovación y Modernidad:** Empleo de un stack tecnológico avanzado (Python, ELK, Vue 3) reflejado en una interfaz rápida, oscura y futurista.

## 3. Identidad Visual

El diseño visual de MercaIntelligence está construido sobre la dualidad entre el sector de consumo ("Merca") y el mundo del análisis de datos ("Intelligence").

### 3.1. Logotipos y Simbología

El isotipo principal combina la letra **"M"** con una **gráfica de tendencia ascendente**. 

*   **Logo de Navegación (`logo-nav.svg`):** Es la representación principal de la marca. Consiste en una "M" geométrica de trazo grueso, sobre la cual se entrelaza una línea de tendencia (representando el análisis de precios) que comienza con un bucle dinámico en la parte inferior izquierda, cruza la figura y se eleva hacia la derecha marcando hitos o "puntos de datos" con círculos.
*   **Favicon (`logo.svg`):** Una versión simplificada de la M-Gráfica, optimizada para su visibilidad en resoluciones pequeñas (pestañas del navegador).

### 3.2. Paleta de Colores

La interfaz se diseña bajo un paradigma **Dark Mode First** para resaltar los datos y gráficos de forma vibrante.

*   **Color Primario (Esmeralda):** `#22c55e`
    *   *Uso:* Resaltar llamadas a la acción, KPIs positivos, y el branding principal. Simboliza el sector supermercado (conectando sutilmente con el verde corporativo de Mercadona) y el éxito/crecimiento financiero.
*   **Verdes Secundarios (Gradientes y Trazos):** `#059669` a `#10b981` y `#34d399`
    *   *Uso:* Trazos de los logotipos, gráficas de tendencia.
*   **Fondos (Space Blue / Dark):** 
    *   Fondo Principal: `#0b0e14`
    *   Superficies/Tarjetas: `#12151e`
    *   *Uso:* Proporciona un contraste profundo (estilo consola/terminal) que evoca un entorno de ingeniería y Big Data.
*   **Acentos:**
    *   Púrpura/Info: `#a855f7` / `#3b82f6` (Para elementos de IA y Machine Learning).
    *   Advertencia/Peligro: `#f59e0b` / `#ef4444` (Para destacar anomalías de precios o reduflación).

### 3.3. Tipografía

*   **Familia Principal:** `Inter` (Google Fonts), con caídas a `system-ui`, `-apple-system`, `sans-serif`.
*   **Justificación:** Inter es una tipografía altamente legible, geométrica y diseñada específicamente para interfaces de usuario y visualización de datos en pantallas. Aporta el tono profesional, analítico y limpio que requiere el proyecto.
